🔗 Connexion Google Sheet

Les données affichées proviennent alors directement de votre classeur — la saisie se fait dans la feuille, ce tableau de bord se contente de l'afficher.

Aucune configuration Google Cloud, aucun droit admin nécessaire. Dans votre feuille : Extensions > Apps Script (là où le script d'ergonomie est déjà installé) > Déployer > Nouveau déploiement > type « Application Web » > Exécuter en tant que « Moi » > Qui a accès : « Tout le monde » > Déployer > autoriser l'accès > copiez l'URL qui se termine par /exec.
Important : Google refuse la connexion si la page est ouverte en double-clic (fichier local) — l'erreur 400 vient de là. Il faut la servir depuis http://localhost via le petit lanceur fourni à côté de ce fichier, puis autoriser http://localhost:8000 dans votre identifiant client Google Cloud. Demandez-moi « comment créer l'identifiant client Google » si besoin d'aide.
